# Temperature Monitor - Lab 5

## Описание

Кроссплатформенная программа на C для мониторинга температуры с HTTP-сервером и базой данных SQLite.

## Функционал

1. **Чтение данных с последовательного порта** - считывание температуры с устройства
2. **Запись в базу данных SQLite** - хранение всех измерений
3. **Вычисление средних значений**:
   - Средняя температура за час (каждый час)
   - Средняя температура за день (каждый день)
4. **Очистка старых данных**:
   - Сырые данные хранятся 24 часа
   - Часовые средние хранятся месяц
   - Дневные средние хранятся год
5. **HTTP-сервер** для доступа к данным через веб-интерфейс
6. **Веб-интерфейс** с графиками (Chart.js)

## API Endpoints

- `GET /` - главная страница с веб-интерфейсом
- `GET /api/current` - текущая температура
- `GET /api/hourly` - почасовые данные за последние 24 часа
- `GET /api/daily` - ежедневные данные за последний месяц

## Требования

- CMake 3.10+
- GCC или Clang
- SQLite3
- pthread (Linux/macOS)

## Использование

### 1. Запуск симулятора температуры

```bash
./bin/temp_simulator
```

### 2. Запуск сервера мониторинга

```bash
./bin/temp_monitor --http 8080 --db /Users/poslam/Downloads/projects/fefu/7/os/labs/5/build/temperature.db
```

Параметры:
- `--http PORT` - порт HTTP-сервера (по умолчанию 8080)
- `--db PATH` - путь к файлу базы данных (по умолчанию temperature.db)
- `--port DEVICE` - последовательный порт (по умолчанию /dev/ttyUSB0)
- `--baud RATE` - скорость передачи (по умолчанию 9600)

### 3. Открыть веб-интерфейс

Откройте браузер и перейдите по адресу: http://localhost:8080
