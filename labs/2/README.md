# Лабораторная работа 2: Кроссплатформенная библиотека для управления процессами

## Описание

Кроссплатформенная библиотека на языке C для запуска программ в фоновом режиме с возможностью ожидания завершения работы дочерней программы и получения кода возврата.

## Структура проекта

- `process.h` - заголовочный файл с API библиотеки
- `process.c` - реализация библиотеки (поддержка Windows и POSIX)
- `test_program.c` - простая программа для тестирования в качестве дочернего процесса
- `test_code.c` - тестовая утилита для проверки функционала библиотеки
- `CMakeLists.txt` - конфигурация сборки
- `build.sh` - скрипт сборки для Linux/macOS
- `build.cmd` - скрипт сборки для Windows

## API библиотеки

### Функции

1. **`start_background_process()`** - запуск программы в фоновом режиме
   - Параметры: путь к программе, массив аргументов
   - Возвращает: дескриптор процесса

2. **`wait_for_process()`** - ожидание завершения процесса
   - Параметры: дескриптор процесса, указатель на код возврата
   - Возвращает: 0 при успехе, -1 при ошибке

3. **`is_process_running()`** - проверка статуса процесса
   - Параметры: дескриптор процесса
   - Возвращает: 1 если работает, 0 если завершен, -1 при ошибке

4. **`close_process_handle()`** - освобождение ресурсов процесса
   - Параметры: дескриптор процесса

```

```

## Тестовые сценарии

Тестовая утилита `test_code` выполняет следующие проверки:

1. **Test 1**: Базовое выполнение процесса
2. **Test 2**: Процесс с аргументами командной строки
3. **Test 3**: Проверка статуса запущенного процесса
4. **Test 4**: Запуск нескольких процессов одновременно
5. **Test 5**: Обработка ошибок (несуществующая программа)

## Кроссплатформенность

Библиотека поддерживает:
- **Windows**: использует Windows API (CreateProcess, WaitForSingleObject)
- **POSIX** (Linux, macOS, BSD): использует fork/execv/waitpid

Автоматическое определение платформы через макросы `_WIN32`.

## Требования

- CMake 3.10 или выше
- Компилятор C99 (gcc, clang, MSVC)
- Операционная система: Windows, Linux, macOS

## Примеры использования

```c
#include "process.h"

int main() {
    // Запуск простой программы
    char* args[] = { NULL };
    process_handle_t handle = start_background_process("./my_program", args);
    
    // Ожидание завершения
    int exit_code;
    wait_for_process(handle, &exit_code);
    printf("Exit code: %d\n", exit_code);
    
    // Освобождение ресурсов
    close_process_handle(handle);
    
    return 0;
}
```
